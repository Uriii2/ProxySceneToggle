# ProxySceneToggle

Переключатель Сценария настройки системного прокси Windows в один клик из системного трея.
Больше не нужно каждый раз лезть в **Параметры → Сеть и Интернет → Прокси-сервер - Использовать сценарий настройки** —
вкл/выкл прокси делается одним кликом по иконке рядом с часами.

В отдельных случаях, когда реализована маршрутизация прокси через pac-файл, необходимо временно отключать сценарий настройки прокси. 
Данная реализация облегчает эту работу.


## Возможности

- **Левый клик** по иконке в трее → включить/выключить сценарий настройки прокси
- **Зелёная иконка с галочкой** — сценарий настройки прокси включён
- **Серая иконка** — прокси сценарий настройки выключен
- **Правый клик** — меню: статус, переключить, выход
- Изменения применяются **мгновенно** (через WinINet API), перезагрузка не нужна
- Защита от запуска второй копии
- Один файл `.exe`, без установщика и зависимостей (кроме .NET Framework, который уже есть в Windows)

Меняются те же настройки, что в системном окне «Прокси-сервер» — программа просто
переключает их быстрее.

## Совместимость

Работает на **Windows 11** (32- и 64-бит). На более младших версиях не протестировано.
Требуется .NET Framework (2.0 или новее) — на Windows 8/10/11 он встроен,
на Windows 7 может потребоваться [доустановить .NET Framework 4.x](https://dotnet.microsoft.com/download/dotnet-framework).

## Быстрый старт

1. Скачай репозиторий (зелёная кнопка **Code → Download ZIP** или `git clone`)
2. Запусти `build.bat` двойным кликом
3. Появится `ProxySceneToggle.exe`
4. Запусти `ProxySceneToggle.exe` — иконка появится в трее

Сборка идёт встроенным в Windows компилятором C# (`csc.exe`), интернет и
сторонние инструменты не нужны. Батник сам находит нужную версию .NET.

> Готовый `.exe` в репозитории намеренно не хранится — каждый собирает его




## Чтобы иконка не пряталась

По умолчанию Windows прячет новые иконки под стрелку «˅».
Чтобы закрепить её на видном месте:

**Windows 11:** Параметры → Персонализация → Панель задач →
Другие значки на панели задач → включи **ProxySceneToggle**


## Автозапуск при включении компьютера

1. Нажми `Win + R`, введи `shell:startup`, Enter
2. В открывшуюся папку положи **ярлык** на `ProxySceneToggle.exe`

Готовый помощник: `install-autostart.bat` создаёт ярлык автозапуска автоматически.

## Как это работает

Программа меняет два значения в реестре пользователя
(`HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings\Connections`):

- `DefaultConnectionSettings` — показатель бинарного типа Reg_Binary. 
	Утилита меняет значение его 9-го бита, из за которого Windows "понимает" включен в данный момент сценарий настройки прокси, или нет. 
	Хотя в интерфейсе Windows переключатель настройки может именть другое значение.

После записи вызывает `InternetSetOption` (WinINet), чтобы система и браузеры
подхватили изменения сразу, без перезагрузки.
